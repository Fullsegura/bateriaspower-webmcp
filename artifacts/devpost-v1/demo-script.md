# Demo script — 110 seconds

## Recording setup

- Record at 1920 × 1080.
- Browser zoom: 100%.
- Keep the cursor visible and movements deliberate.
- Use the public URLs, not localhost.
- Record the customer and advisor views in separate browser windows.
- Use English narration and captions.

## Script and shot list

### 0:00–0:10 — Problem and promise

**Visual:** Open `https://webmcp.fullsegura.com/search`.

**Narration:**

“Finding the right car battery usually means searching multiple pages and repeating vehicle details to support. BateríasPower turns that fragmented journey into one guided experience.”

**Caption:** `From vehicle intent to a compatible battery`

### 0:10–0:28 — Natural-language search

**Visual:** Enter `Toyota Corolla 2018 motor 1.8` and select **Buscar**.

**Narration:**

“The customer simply describes the vehicle. Gemini understands the request, and Google ADK coordinates the task.”

**Caption:** `Natural-language vehicle search`

### 0:28–0:46 — Native WebMCP action

**Visual:** Show the agent response and the catalog updating to compatible products.

**Narration:**

“The agent invokes native WebMCP functions inside the browser. The visible storefront updates in place, so the customer can see and verify every action.”

**Caption:** `Native WebMCP updates the live UI`

### 0:46–1:00 — Select and prepare cart

**Visual:** Select a battery, show its detail, and add it to the cart.

**Narration:**

“The customer can compare specifications, select a compatible option, and prepare an informational quote cart without leaving the conversation.”

**Caption:** `Selection + informational quote cart`

### 1:00–1:13 — Mobile experience

**Visual:** Briefly show the responsive mobile layout and open the agent bottom sheet.

**Narration:**

“On mobile, the agent uses a bottom sheet so the chat and catalog remain available together.”

**Caption:** `Mobile-first and accessible`

### 1:13–1:35 — Human handoff

**Visual:** Enter a customer name, select **Hablar con asesor**, and show the incoming call dialog in `/advisor`.

**Narration:**

“When human expertise is needed, the customer starts a live handoff. The advisor answers a bidirectional LiveKit voice call while text chat remains available.”

**Caption:** `Live voice + text handoff`

### 1:35–1:50 — Context and product image

**Visual:** Show the advisor workspace with customer, vehicle, conversation, selected battery, and product image. Exchange one short text message.

**Narration:**

“The advisor receives the vehicle, conversation history, selected product, and product image. The customer never has to repeat the story.”

**Caption:** `Full context reaches the advisor`

### 1:50–1:58 — Close

**Visual:** End on the synchronized customer and advisor experience or the BateríasPower logo.

**Narration:**

“BateríasPower shows how WebMCP can turn a website into an AI-operable, human-supported sales experience.”

**Caption:** `BateríasPower — Search-to-Sale with WebMCP`

## Final recording checklist

- WebMCP status reads **conectado**.
- Search returns compatible products.
- Product image is visible in the advisor workspace.
- Bidirectional audio is confirmed before recording.
- Live text is exchanged during the call.
- No browser console or Next.js error overlay is visible.
- Final video duration is between 90 and 120 seconds.
