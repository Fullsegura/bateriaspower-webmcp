## Gallery

All gallery images are PNG, 1500 × 1000 (3:2), and under 5 MB.

1. `01-smart-search.png` — Describe a vehicle in plain language to start a guided battery search.
2. `02-webmcp-catalog.png` — Gemini uses native WebMCP tools to update the product catalog in place.
3. `03-cart-selection.png` — Select a compatible battery and add it to an informational quote cart.
4. `04-mobile-chat.png` — The mobile bottom sheet keeps the catalog and AI agent visible together.
5. `05-voice-handoff.png` — Escalate to a live voice advisor while preserving chat and selected-product context.
6. `06-advisor-view.png` — The advisor receives the customer, vehicle, selected product, image, voice, and live text in one workspace.
